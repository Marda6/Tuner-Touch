# ENCY Tuner Touch

Прототип сенсорного интерфейса ENCY Tuner 3 для стойки FANUC PANEL iH Pro (19" 1280×1024 и 1920×1080).

**Открыть:** https://marda6.github.io/Tuner-Touch/

Стенд показывает экран стойки в натуральную величину. Сверху переключатели: вариант, разрешение, шрифт и значки, язык EN / RU и заметки к блоку на ревью. Справа — решения по блоку и демо-состояния вкладки.

## Три варианта

Переключатель **«Вариант»** на стенде:

- **Новый дизайн** — интерфейс, спроектированный заново: операции внутри текста УП, пульт по смыслу, шкала моделирования, кубик вида.
- **Из компонентов Tuner** — раскладка ТЗ, собранная из того, что в Tuner уже есть, под палец: список операций как дерево наладки, редактор УП с отметками, панель моделирования Tuner в её порядке, окно «Проверки», клавиши вида и режим тел вращения 3D / ¾ / ½.
- **Панели ENCY Core** — настольный прототип Tuner на ENCY Core (копия в `core/`) как есть, увеличенный под палец (×1,83: строка 24 → 44 px) и переложенный под экран стойки: дерево «Setup» над кодом с каналами, «Parameters» на месте кода по переключателю, справа 3D с его панелями.

У первых двух вариантов данные, моделирование и 3D общие; у третьего — свои, как в настольном прототипе (3D там заглушка).

## Что собрано

1. **Верх** — вкладки проектов и окно; станок, каналы, программа, «Сохранить».
2. **Программа** — текст УП с операциями-гармошкой, отметками и ошибками под строкой.
3. **3D** — сцена из текста УП (three.js): кубик вида, жесты, видимость, Verify Compare, подлёт камеры к ошибке.
4. **Пульт и шкала моделирования** — «Пуск», шаги, скорость, ошибки, проверки.

Моделирование условное: станок идёт по кадрам УП показанного канала, ошибки заложены в демо-данных. Настоящие расчёт и моделирование делает Tuner.

## Локально

Статика без сборки: откройте `index.html` через любой локальный сервер, например

```bash
npx serve .
```

three.js 0.187 лежит в `vendor/three` (лицензия MIT).
